# Hematovision-_miniproject
HematoVision is a computer vision–based mini project designed to analyze microscopic blood sample images. The system processes blood smear images to identify and count different types of blood cells such as red blood cells (RBCs) and white blood cells (WBCs).
# HematoVision

HematoVision is an image processing based mini project designed to analyze microscopic blood cell images.

## Project Description
This project detects and classifies Red Blood Cells (RBCs) and White Blood Cells (WBCs) using image processing techniques.

## Technologies Used
- Python
- OpenCV
- NumPy

## Features
- Blood cell detection
- Cell classification
- Image preprocessing

## Conclusion
This project demonstrates the application of computer vision techniques in medical image analysis.
